# Home featured-hero art

Background for the featured hero at the top of `/team` (see `features/team/home/FeaturedHero.tsx`).
Only use art we own or have a written licence for.

- Name files `hero-bg-*.webp` (several rotate once a day, sorted by name).
- Wide landscape, at least 1900×800, subject (character) right of centre — the left ~40% sits under the
  headline and is darkened, the bottom fades into the page.
- WebP quality ~80, aim for < 300 KB.
